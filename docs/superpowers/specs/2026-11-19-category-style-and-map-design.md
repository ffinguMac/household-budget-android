# 카테고리 색·이모지 통일 + 통계 맵 개편 설계

작성일 2026-11-19 · 기준 브랜치 `master` (9b9ee4d)

## 의도
통계 탭의 "맵"이 보기 불편하다(색이 "전월 대비"를 뜻해 범례를 읽어야 하고, 글씨가 작고, 남은 돈·저축이 지출과 섞임). 맵을 새로 다듬으면서 카테고리 색·이모지를 도입하는데, 이게 맵에만 있으면 따로 노니 **카테고리가 나오는 모든 곳에서 같은 색·이모지**를 쓰게 한다. 화면 구조(레이아웃)는 맵 외에는 바꾸지 않는다.

## 목표 / 비목표
- 목표: 카테고리 스타일(색 + 이모지)을 한 곳에서 정의해 전 화면에 적용. 맵을 A+B 합친 안으로 교체.
- 비목표: 홈·내역·달력 등 다른 탭의 구조 개편, 다크/라이트 테마 자체 변경, 리포트 모드의 구조 변경.
- 실패 조건: 같은 카테고리가 화면마다 다른 색/아이콘으로 보임. 맵에서 지출 합계와 요약 숫자가 안 맞음.

## 검토한 안 (사용자 선택: ②)
| 안 | 내용 | 결정 |
|---|---|---|
| ① 맵만 | 맵만 개편 | 기각 — 맵에서만 색·이모지가 보여 따로 놂 |
| ② 공통 요소 맞추기 | 카테고리 스타일 한 곳 정의 + 카테고리 노출 지점에 적용 | **채택** |
| ③ 전체 탭 리디자인 | 모든 탭 구조 재설계 | 기각(범위 과대, 필요 시 별도 프로젝트) |

## 사용자가 정한 것
### 맵 화면 (A + B 시안, 브라우저 시안 `map-ab2.html`과 동일한 구성)
1. **상단 요약 (A)**: "11월 지출" 라벨, 지출 합계(큰 숫자), "수입 N만 중 X% · 저축 N만 · 남은 돈 N만" 한 줄, 그 아래 **지출/저축/남은 돈 가로 비율 막대** + 작은 범례 3개. 수입이 0이면 비율·남은 돈 문구와 막대는 숨기고 지출 합계만. 지출+저축 > 수입이면 남은 돈 대신 "초과 N만"(빨강)으로 막대 표시.
2. **트리맵 (A 스타일)**: 지출 대분류만(저축·남은 돈 타일 없음). 타일 = 카테고리 색 15% 배경 + 50% 테두리, 둥근 모서리(14dp), 넓은 간격(6dp). 큰 타일엔 이모지·이름·금액·비율·전월 대비(▲/▼ n%, ±5% 이내는 "–"), 중간 타일엔 이모지·이름·금액, 작은 타일엔 이모지만. 높이 약 230dp. 범례 행 삭제.
3. **순위 목록 (B)**: 트리맵 아래 지출 대분류 전부를 금액 내림차순. 행 = 색 점, 이모지+이름, 최대값 대비 가로 막대, 금액, 전월 대비(▲ 빨강 / ▼ 초록 / – 회색).
4. **탭 동작**: 타일·목록 행을 누르면 기존처럼 그 대분류의 거래 목록 시트가 열린다(기존 `sheetForTileKey`/`TransactionsSheet` 재사용).

### 카테고리 스타일 적용 지점
- 거래 행 `ui/components/TransactionRow.kt`: 첫 글자 원 → **카테고리 색 원(약 15~20% 틴트) + 이모지**. 피드·달력·아카이브·통계 시트 등 모든 호출처가 자동 적용.
- 통계 "리포트"의 카테고리 예산 카드(`CategoryBudgetCard`): 행 앞에 이모지, 막대 색을 카테고리 색으로.
- 카테고리 선택 UI: 거래 입력 화면(`EditTransactionScreen`)과 "확인 필요" 시트(`PendingReviewScreen`)의 대분류 표시에 이모지(색 점 또는 칩 테두리).
- 예산 설정(`BudgetSettingsScreen`)의 대분류 목록에 이모지.

## 작성자 판단
- 스타일 출처: `FixedCategories.TREE`에 이미 있는 대분류 이모지를 그대로 쓴다. 색은 app 모듈 `ui/theme`에 대분류 이름 → 색 매핑으로 둔다(시안 팔레트: 식비 #FF8A65, 교통 #4FC3F7, 생활 #AED581, 쇼핑 #BA68C8, 여가 #FFD54F, 기타 #90A4AE, 유동 지출 #F06292, 수입 #64B5F6, 저축 #4DB6AC). 소분류는 부모 대분류 스타일을 따른다. 매핑에 없는 이름(이론상 없음)은 회색 + 이름 첫 글자.
- 조회 키: 거래 행에는 대분류 이름이 있으므로(`parentCategoryName`, 없으면 `categoryName`) 이름으로 찾는다. DB 변경 없음.
- 기존 맵의 "작은 타일 기타로 합치기"는 대분류 7개뿐이라 제거하되, 1.5% 미만 타일은 이모지만 보이게 처리.
- 기존 전월 대비 5단계 색(MapDeepGreen 등)과 범례는 삭제.
- 접근성: 트리맵 contentDescription은 "식비 48만 원, 지난달보다 14% 증가…" 식으로 유지·확장.
